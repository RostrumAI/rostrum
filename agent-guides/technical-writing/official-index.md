# Official writing source index

Use this index when a task needs explicit Google Style Guide compliance or a specialized rule. Read only the applicable source page and local guidance file. Do not load unrelated categories.

This index covers the Google pages that contain writing, formatting, accessibility, interface, linking, or naming rules. It does not treat `What's new` or `Philosophy of this guide` as writing requirements. The root guide remains the authority and orientation page.
